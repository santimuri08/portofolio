# Spec: Style (Phase 3)

The visual direction that makes the archetype legible.

---

## Color palette

| Role       | Hex       | Why                                          |
|------------|-----------|----------------------------------------------|
| Background | `#0B0F19` | Near-black with blue depth. Calm, not harsh. |
| Primary    | `#2563EB` | Confident blue. Action, links, signature.    |
| Accent     | `#22C55E` | One green moment per page. Controlled energy.|

## Typography

- **Family:** Inter (or similar modern geometric sans)
- **Hero:** 56–72px, weight 600
- **H2:** 32–40px, weight 600
- **Body:** 16–18px, weight 400, line-height 1.6
- **Caption / meta:** 13–14px, weight 500, tracked slightly

## Grid & spacing

- 12-column grid, 24px gutter
- Max content width: 1200px
- Vertical rhythm: multiples of 8px
- Generous section padding (minimum 96px top/bottom)

## Signature move: Calibrated restraint

_What this means concretely:_
- Mostly monochrome (background + foreground)
- Blue used sparingly — links, one CTA per view
- Green used once per page max, as a deliberate accent
- No gradients, no shadows by default
- One moment of motion per page, never more
