# Swiss Style (International Typographic Style)

Origin: Switzerland, 1950s. Designers like Josef Müller-Brockmann and
Armin Hofmann. The core idea: design should communicate cleanly, not decorate.

## Core Principles

### Grid as Foundation
Every element sits on an invisible grid. Columns, gutters, baselines.
The grid creates order without being visible. Breaking the grid is
intentional and rare.

### One Message Per Screen
Each view communicates a single primary idea. Supporting content reinforces
that idea; it does not compete with it. If a visitor had to leave after
three seconds, what one thing should they remember?

### Typography as Image
Typefaces are chosen carefully and used systematically. Hierarchy comes
from size, weight, and spacing — not decoration. Usually one sans-serif
family, used across 2–4 sizes.

### Whitespace as Content
Empty space is not wasted space. It directs the eye, separates ideas,
and signals confidence. Cluttered designs say "I had too much to say."
Spacious designs say "This is what matters."

### Asymmetric Balance
Symmetry is safe but static. Swiss layouts use asymmetric compositions
balanced by weight and whitespace, creating tension that keeps the eye moving.

## Application to This Portfolio

- 12-column grid, generous gutters
- Inter (or similar modern sans) as the single type family
- Headline / body / caption as the main three sizes
- Whitespace around the hero signals confidence, not emptiness
- Asymmetric hero: claim left, nothing right, balanced by scale

## Anti-patterns

- Using the grid as a cage (everything centered, everything symmetric)
- Decorative typography (script fonts, excessive weights)
- Filling whitespace out of nervousness
- More than one "hero" element per screen
