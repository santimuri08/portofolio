# Maslow's Hierarchy Applied to UX

A framework for ordering what a site must deliver, from base layer up.
Lower layers must work before higher ones register.

## The Five Layers

### 1. Functional
The site loads, links work, nothing is broken. Text is readable, images render,
navigation doesn't dead-end. Without this, nothing else matters.

### 2. Reliable
Consistent across pages and visits. Fast. No surprises. A user who clicked a
project card yesterday should get the same experience today.

### 3. Usable
Easy to scan, easy to find what you came for. Hierarchy is obvious.
A hiring manager can find a project in under 10 seconds.

### 4. Convenient
Feels smooth. Transitions are calm, not jarring. Reading feels effortless.
The site respects the user's time and attention.

### 5. Pleasurable
Moments of delight. A signature move. Something that makes the visitor
remember the site and associate that memory with the person behind it.

## Application to This Portfolio

- **Functional:** Deploys without errors, all project links work, images load
- **Reliable:** Consistent typography and spacing across project pages
- **Usable:** Hero states the claim in one sentence; featured project visible without scrolling far
- **Convenient:** Case studies follow the same structure so scanning gets easier, not harder
- **Pleasurable:** Calibrated restraint — calm structure with one controlled moment of energy per page

## Anti-patterns

- Skipping Functional to chase Pleasurable (animated hero on a broken site)
- Adding "delight" at the cost of Usable (clever nav no one can find)
- Confusing Pleasurable with busyness
